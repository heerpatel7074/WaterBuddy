## 🌊 About WaterBuddy

WaterBuddy is a Python-based hydration tracking web application developed using Streamlit. It helps users monitor their daily fluid intake, establish personal hydration goals, and track their progress through an interactive ocean-themed interface.

The application combines Python programming, calculations, user interaction, visual feedback, and reminder features to make daily hydration tracking more engaging.

## ✨ Key Features

- **Daily Intake Tracking:** Record drinks and monitor fluid consumption.
- **Personalised Hydration Goals:** Set a daily intake target through the guided setup.
- **Quick Drink Logging:** Add preset quantities or enter a custom amount.
- **Beverage Tracking:** Record different beverages with their respective hydration credits.
- **Interactive Ocean Dashboard:** Explore visual feedback that responds to hydration progress.
- **Hydration Reminders:** Configure remindersand snooze reminders.
- **Progress Monitoring:** View intake, remaining amounts, and goal completion.
- **Achievements and Milestones:** Receive feedback as progress milestones are reached.
- **Drink History:** Review logged drinks and undo the most recent entry.
- **Daily Reset:** Reset the day's tracking when required.
